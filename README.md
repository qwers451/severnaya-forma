# Северная Форма

Статический демонстрационный интернет-магазин дизайнерской мебели, вдохновлённый эстетикой русского северного минимализма.

- 64 товара без бэкенда
- фильтры, категории, сортировка и поиск
- корзина и избранное с сохранением в браузере
- демо-регистрация, вход и личный кабинет
- оформление заказа, контактные данные и история заказов
- карточки товаров, формы и интерактивные заглушки
- адаптивная вёрстка для телефона, планшета и компьютера

Открыть локально: `index.html`. Для публикации на GitHub Pages выбрать ветку `main`, папку `/ (root)`.

Проект является самостоятельной демонстрационной работой и не связан с Valkeda.
